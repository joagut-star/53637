README

Este proyecto implementa un analizador léxico, sintáctico e intérprete básico utilizando ANTLR4 con JavaScript.

El analizador procesa un archivo input.txt, verifica la validez del código fuente, genera la tabla de tokens, construye el árbol sintáctico y traduce el código a JavaScript para su ejecución.
